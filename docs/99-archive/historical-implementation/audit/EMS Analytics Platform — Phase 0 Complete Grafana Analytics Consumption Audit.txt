EMS Analytics Platform — Phase 0: Complete Grafana Analytics Consumption Audit

Method: all 7 dashboard JSON files were read in full (6,123 lines total — every panel, every query, every variable, every transformation/threshold/annotation field was inspected directly, not sampled). Facts only; no redesign recommendations.

---

Dashboard 1 — alarms.json ("EMS | Alarms", uid ems-alarms)

Purpose: live view of currently-active alarm-equivalent conditions, org-wide, filterable by severity. Workflow: operator/facility-manager triage. Time range: now-24h/now, refresh 1m. Variables: severity (multi-select, query: SELECT DISTINCT severity ... FROM analytics.v_grafana_active_alarms WHERE grafana_org_id=${__org.id}). No annotations, no repeats, no library panels.
