===============================================================================
1. THE CORE PROBLEM: TWO UNRECONCILED PHASE-LETTERING SCHEMES, AND ACTUAL
   EXECUTION ALREADY DIVERGED FROM BOTH
===============================================================================

Two source documents each propose a phase sequence, and they do not use the
same lettering for the same content:

Architecture Gap Analysis (Phase 0 -> Phase 1 Transition), §B:
    Phase A - operational hygiene (job-schedule drift, one tenant-safety grant)
    Phase B - semantic consolidation (reconcile the energy/demand/connectivity
              duplicate implementations to their proven-correct originals)
    Phase C - resolution-routing consistency across all Grafana-facing energy
              readers
    Phase D - environment quality classification
    Phase E - dashboard SQL review
    Phase F - staging commissioning
    Phase G - Analytics API design

Phase 1 Canonical Semantic Model — Final Reconciliation, §F:
    Phase 1A - semantic decisions
    Phase 1B - job-schedule correction (independent)
    Phase 1C - energy-consumption consolidation
    Phase 1D - resolution routing
    Phase 1E - quality model completion
    Phase 1F - Grafana migration to canonical objects
    Phase 1G - staging commissioning
    Phase 2  - Analytics API

Neither document's sequence is what was actually executed:
    Actual Phase 1A = connectivity semantic consolidation only (one slice of
        Gap Analysis's Phase B / Reconciliation's "semantic decisions" bucket)
    Actual Phase 1B = an energy-consumption CONTRACT TEST proving the
        canonical calculation correct — explicitly NOT the full "energy-
        consumption consolidation" the Reconciliation's own "1C" describes,
        and explicitly NOT the job-schedule correction the Reconciliation's
        own "1B" describes.

The job-schedule correction that both documents place early (Gap Analysis
Phase A; Reconciliation 1B) has still not been done — re-confirmed this
session in the Phase 1B CI/CD staging verification log (FAIL: normalization
job schedule/overlap drift, energy/environment routing job overlap drift, all
still present on staging as of commit 5510200).

The Phase 1B Implementation Plan itself (the most recent, most authoritative
statement of sequencing intent) explicitly states energy-consumption CONSUMER
MIGRATION — the remainder of the Reconciliation's literal "1C" bucket — is
"deliberately deferred to a later phase, once resolution-routing (a separate,
already-identified gap) is also addressed." That is a direct, first-party
statement that resolution-routing (Reconciliation's 1D / Gap Analysis's Phase
C) is a PREREQUISITE for finishing what the Reconciliation called 1C — which
means treating "Phase 1C" as "finish energy-consumption consolidation now"
would contradict the project's own most recent stated dependency ordering.
